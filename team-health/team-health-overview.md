# Team Health

**Team Health** (in the **Teams & Organization** section of the left menu) is where you manage teams, developer profiles, and their tool accounts, and open each team's scorecard.

### Tabs

| Tab          | What it shows                                                                                                                                                                                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Teams**    | Your teams as a tree that follows the organization hierarchy, with each team's **Lead(s)**, **Members**, **Repositories**, connected **Tools**, and **Action** buttons. The first row of the tree is open by default. Use **+ Team** to [add a team](https://docs.oobeya.io/team-health/adding-a-team). |
| **Profiles** | Developer profiles. Developer tags are assigned here, in the profile **Update** form, and in a team's **Manage Members** dialog. See [Adding A Profile](https://docs.oobeya.io/scorecards/adding-a-profile).                                                                                            |
| **Accounts** | Tool accounts (for example Git authors) and their matching to profiles. A warning badge shows when there are accounts that need attention. See [Merging Contributor Accounts](https://docs.oobeya.io/gitwiser-repo-analytics/settings-for-git-analytics/merging-contributor-accounts).                  |

On the **Teams** tab you can search teams, choose visible columns, clear filters, and **export the table to Excel**.

### Team Scorecard

Open a team to see its **Team Scorecard**: delivery, code, quality, and project metrics of the team for the selected period. The scorecard configuration lists the data sources (Git analyses, boards, code quality projects, and more) selected for the team and shows how many items are selected for each integration, both on screen and in the Excel export. See [Team Scorecard](https://docs.oobeya.io/team-health/team-scorecards).
