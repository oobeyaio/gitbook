# Oobeya MCP

The Oobeya MCP server connects the AI tool you already use to Oobeya. Ask about your teams' delivery, pull requests, sprints and quality in plain language, and get answers from the same data you see in the Oobeya UI. Every request runs with your own Oobeya account and permissions.

Available from Oobeya 2.1.0. Supported AI tools: Claude Code, Codex, Cursor, VS Code, Devin (Windsurf), GitHub Copilot, Gemini CLI, Grok Build and OpenCode.
