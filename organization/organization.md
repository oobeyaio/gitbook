# Organization

**Organization** (the **Organization Stats** page) lets senior leadership monitor the metrics of organizational units. It rolls engineering metrics up the team hierarchy, so you can compare divisions, departments, and teams and drill down to where action is needed.

{% hint style="info" %}
Organization can be turned on or off in **Administration** > **Feature Management** (**Modules**). The hierarchy comes from your teams and their organization levels; see [Adding A Team](https://docs.oobeya.io/team-health/adding-a-team) and **Administration** > **Organizational Chart**.
{% endhint %}

### Teams

The **Teams** list shows every unit as a tree, with its **Lead(s)**, **Members**, **Repositories**, and connected **Tools**. Open a unit to see its statistics.

### Unit statistics

For the selected unit and period, Organization shows:

| Section                     | What it shows                          |
| --------------------------- | -------------------------------------- |
| **Team Details**            | The unit and its sub-teams.            |
| **Statistics**              | Headline metrics of the unit.          |
| **Coding Activities**       | Commit and coding activity.            |
| **Pull Request Activities** | Pull request activity.                 |
| **PR Review Stats**         | Code review statistics.                |
| **Code Changes**            | Code changes of the unit.              |
| **AI Statistics**           | AI coding assistant usage of the unit. |
| **Test Quality Report**     | Test quality of the unit.              |
