# Metrics List

View a comprehensive list of the metrics in Oobeya, organized into categories. Each category page lists every metric in that module with a short definition.

What you see for a metric can depend on:

* User permissions
* Team, repository, project, and data-source mappings
* Selected date range
* Organization-specific configuration

{% hint style="info" %}
Oobeya metrics should be interpreted together and within the context of each team. A single metric should not be used as an individual performance target.
{% endhint %}
