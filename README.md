# Welcome to Oobeya!

Oobeya is a software engineering intelligence platform. It connects to the tools your teams already use (source code management, CI/CD, project management, code quality, testing, monitoring, and AI coding assistants) and turns their data into team scorecards, DORA metrics, symptoms, and AI impact reports.

This documentation explains how to install and set up Oobeya, connect your tools, and read the metrics.

### How Oobeya works

1. **Connect your tools.** Add a data source for each tool on the [Integrations](https://docs.oobeya.io/integrations/adding-new-integration) page.
2. **Set up your organization.** Add users and developer profiles, match their tool accounts, and build teams that follow your organizational chart.
3. **Start analyses.** Analyze repositories, pipelines, boards, and code quality projects, then select them in each team's scorecard.
4. **Read and act.** Team scorecards, DORA metrics, symptoms, and AI impact reports show where teams do well and where they need attention.
5. **Track over time.** Compare periods and teams with Trend Reports, Organization, and engineering benchmarks.

* [Oobeya REST API](https://docs.oobeya.io/api-reference/oobeya-rest-api) and [API Keys](https://docs.oobeya.io/administration/api-keys): automate Oobeya and send data from other tools.
