# AI Coding Assistants

Oobeya brings adoption, usage, acceptance, and cost data from AI coding assistants into **AI Impact**, next to the delivery and quality metrics of the same teams.

| Tool           | What Oobeya reads                                                                                                                 | Guide                                                                                                              |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Claude Code    | Usage and activity sent over OpenTelemetry through the Oobeya Collector; seats and billed cost with an optional Anthropic API key | [Claude Code - AI Impact](https://docs.oobeya.io/ai-impact/claude-code-ai-impact)                                  |
| Codex          | Codex usage and cost from a ChatGPT Enterprise workspace                                                                          | [Codex Integration](https://docs.oobeya.io/integrations/all-integrations/ai-coding-assistants/codex-integration)   |
| Cursor         | Cursor usage per team                                                                                                             | [Cursor Integration](https://docs.oobeya.io/integrations/all-integrations/ai-coding-assistants/cursor-integration) |
| GitHub Copilot | Copilot seats, usage, and acceptance from GitHub                                                                                  | [GitHub Copilot - AI Impact](https://docs.oobeya.io/ai-impact/github-copilot-ai-impact)                            |
