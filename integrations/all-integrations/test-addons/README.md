# Test

These tools are in the **Test** category of the Integrations page. Their data feeds Test Analytics.

| Tool                                                 | What Oobeya reads                               | Guide                                                                                                                 |
| ---------------------------------------------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Xray (Server / Data Center and Cloud)                | Test executions, test cases, and linked defects | [Xray Integration](https://docs.oobeya.io/integrations/all-integrations/code-quality-addons/xray-integration)         |
| Zephyr (Server / Data Center and Zephyr Scale Cloud) | Test projects and execution results             | [Zephyr Integration](https://docs.oobeya.io/integrations/all-integrations/test-addons/zephyr-integration)             |
| TestRail                                             | Test runs and results                           | [TestRail Integration](https://docs.oobeya.io/integrations/all-integrations/code-quality-addons/testrail-integration) |
| Testinium, Testinium Cloud                           | Automated test plans and execution results      | [Testinium Integration](https://docs.oobeya.io/integrations/all-integrations/test-addons/testinium-integration)       |

* [Zephyr Integration](https://docs.oobeya.io/integrations/all-integrations/test-addons/zephyr-integration)
* [Testinium Integration](https://docs.oobeya.io/integrations/all-integrations/test-addons/testinium-integration)
