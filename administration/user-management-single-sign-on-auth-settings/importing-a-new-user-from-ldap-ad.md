# Importing a New User From LDAP / Active Directory

You can **import users** from the LDAP / AD of your organization, after [configuring LDAP](https://docs.oobeya.io/administration/user-management-single-sign-on-auth-settings/configuring-ldap-active-directory) settings on the Oobeya Administration Panel.

Follow the steps below to import new users from LDAP / AD.

1. Select **Administration** in the left menu, then **User Management** in the **Organization** section.
2. Open the **Users** tab.
3. Click the "**New User**" button.

![](https://3582076375-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-MGIlBSTjQtZxUoFwUx4%2F-MHABFh59_7wcb57FRKm%2F-MHAIY2qglvri_vJMxTL%2Fimage.png?alt=media\&token=6e1b4d54-9808-431e-a477-942c53117cd1)

4\. Click **"Import User from LDAP"**.

![](https://3582076375-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-MGIlBSTjQtZxUoFwUx4%2F-MHABFh59_7wcb57FRKm%2F-MHAJzZ1yaIQtOyXPaWD%2Fimage.png?alt=media\&token=03c6290e-c625-4034-93c3-7054ebfb2015)

5\. Enter the name / username / email of the user and click **Search**.

![](https://3582076375-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-MGIlBSTjQtZxUoFwUx4%2F-MHABFh59_7wcb57FRKm%2F-MHAKkXfiExRYfH8CXCV%2Fimage.png?alt=media\&token=20beb99b-8897-44a6-b5bc-8c6b7f060fb1)

6\. Select the user that you want to add and then click **Import**.

![](https://3582076375-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-MGIlBSTjQtZxUoFwUx4%2F-MHABFh59_7wcb57FRKm%2F-MHALb_nXSzEjE0exS4E%2Fimage.png?alt=media\&token=453ab932-cdbc-449f-8987-3985a61b05d2)

7\. Now you can change the default application role and company role of the user.
