# Updating The License Key

1. Sign in with an **Administrator** account and select **Administration** in the left menu.
2. In the **Platform** section, select **License Management**.
3. Enter or renew your license key. The page also shows the license expiration date and limits.

{% hint style="success" %}
Ready! If you have any questions about your license please [reach out to us](https://oobeya.io/contact/).
{% endhint %}
