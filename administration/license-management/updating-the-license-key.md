# Updating The License Key

Enter a new or renewed license key when you first set up Oobeya, when your license is about to expire, or when you move to another plan.

{% stepper %}
{% step %}
#### Get a key for your server

Sign in with an **Administrator** account, select **Administration** in the left menu, then **License Management** in the **Platform** section. Copy the **Server ID** and send it to the [Oobeya Sales Team](https://oobeya.io/contact-sales/). Your license key is created for this Server ID.
{% endstep %}

{% step %}
#### Enter the key

Paste the key into the **License Key** field. Do not add spaces or line breaks.
{% endstep %}

{% step %}
#### Save

Click **Save**. The page shows the new **License Type**, **Expiry Date**, limits, and **Licensed Features**. Click **Reset** instead to discard what you typed.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
A key works only on the server it was created for. If you see **This license key does not belong to this server**, ask for a key for the Server ID shown on the page.
{% endhint %}

See [License Management](https://docs.oobeya.io/administration/license-management) for what each field means and for the other error messages.
